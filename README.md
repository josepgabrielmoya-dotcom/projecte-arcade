# Mini Arcade en Python

Aquest projecte consisteix en una màquina recreativa virtual per a consola desenvolupada en Python per al Mòdul 1713 de SMX2. L'aplicació ofereix un menú principal interactiu que permet a l'usuari escollir entre dos minijocs clàssics o sortir del programa de manera senzilla i intuïtiva.

El primer joc és **Pedra, Paper, Tisora**, on el jugador s'enfronta contra un oponent automatitzat (`robot.py`) podent triar entre jugar al primer que arribi a 3 victòries o al millor de 5 rondes. El segon joc és 
**Endevinar el Número**, en el qual el programa genera un nombre aleatori entre l'1 i el 100 i guia l'usuari mitjançant pistes de «Massa alt» o «Massa baix» fins que l'encerta, comptabilitzant el total d'intents realitzats.

## Instruccions d'execució

1. **Requisits previs:** Tenir instal·lat **Python 3** a l'ordinador.
2. **Clonar el repositori:** Descarrega el projecte
